# Sistema de Inventario en C#

Aplicación de consola desarrollada en C# y .NET 8 para gestionar productos y controlar su inventario.

Este proyecto forma parte de mi portafolio de desarrollo de software y tiene como objetivo demostrar fundamentos de programación orientada a objetos, colecciones, LINQ, validación de datos y buenas prácticas de desarrollo.

## Características

- Agregar productos.
- Eliminar productos.
- Buscar productos por ID.
- Mostrar todos los productos.
- Aumentar el stock.
- Reducir el stock.
- Validar IDs.
- Evitar IDs duplicados.
- Validar precios y cantidades.
- Evitar stock negativo.
- Manejar productos inexistentes.
- Manejar cantidades mayores al stock disponible.

## Tecnologías utilizadas

- C#
- .NET 8
- Programación Orientada a Objetos
- LINQ
- Git
- GitHub
